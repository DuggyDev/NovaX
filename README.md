# NovaX
Space-themed chat app.

## .exe bouwen via GitHub
1. Maak een GitHub repo en push alle bestanden naar branch `main`.
2. Ga naar Actions > "Build NovaX .exe" > wacht tot klaar > download artifact **NovaX-Setup**.

## Server
`cd server && npm install && npm start` (poort 3000). Zet in de app het adres, bv. `ws://JOUW-IP:3000`.

## Lokaal testen
`npm install && npm start`
